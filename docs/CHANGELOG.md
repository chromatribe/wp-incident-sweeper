# CHANGELOG

## [2.20261015.9] - 2026-10-15

### Added & Improved
- **全アイコンの Lucide SVG 化（Dashicons からの完全脱却）:**
  - WordPress 古典 Dashicons を全廃し、モダンで美しい Lucide SVG アイコン（`ShieldCheck`, `FileText`, `Users`, `BookOpen`, `Scale`, `Download`, `RotateCw`, `Target`, `CloudDownload`, `X`）へ完全刷新。
  - 管理メニューアイコンにも Lucide Shield SVG の Data URI を適用。
  - 外部CDN不要・フォント読み込みチラつきゼロのインラインSVG方式で描画。
  - 総合テストスイートに `test_lucide_icons` を追加。

## [2.20261015.8] - 2026-10-15

### Added & Compliant
- **国際化・地域化 (i18n / l10n) の完全実装:**
  - WordPress標準 gettext 準拠テキストドメイン `wp-incident-sweeper` および `languages/` 配備。
  - POT テンプレート、日本語 PO、コンパイル済みバイナリ MO を同梱。
  - JavaScript 側への `wpisConfig.i18n` 辞書注入と `__()` / `sprintf()` ヘルパーによる完全な多言語対応。
- **法令遵守（コンプライアンス）& プライバシー対応の完全実装:**
  - **電気通信事業法（2023年6月施行 改正外部送信規律）対応:** GitHub（`raw.githubusercontent.com`）へのシグネチャ取得通信における送信情報（IP、User-Agent）、非送信情報（サイト内コンテンツ・個人データ完全ローカル完結）をUI上で明示開示。
  - **個人情報保護法 (APPI) & GDPR 対応:** `wp_add_privacy_policy_content` によるプライバシーポリシー提案文面の自動登録、および「マイKW (`wpis_my_keywords`)」に対する個人データ開示（`wp_privacy_personal_data_exporters`）と消去（`wp_privacy_personal_data_erasers`）フックを実装。
  - **不正アクセス禁止法遵守 & 利用許諾条項 (AUP):** 正当な管理権原または契約に基づく保守環境に限定する利用規約条項を策定。
  - **免責事項 (Limitation of Liability):** AS-IS（無保証）提供および一括完全削除前の事前バックアップ義務を明文化。
  - **新タブ新設:** 管理画面に第4のタブ「📜 法令・規約・プライバシー (Compliance & Privacy)」を追加し、常時閲覧可能に整備。
- **総合テストスイート拡張:**
  - `test_i18n_l10n_readiness` および `test_compliance_and_privacy` を追加。

## [2.20261015.7] - 2026-10-15

### Added & Improved
- **マイKW（個別検知キーワード指定機能）の実装:**
  - ユーザーメタ（`wpis_my_keywords`）により、管理者ごとに独自の検知対象キーワード（1行1KW）を自由に登録・管理可能。
  - 管理画面ヘッダーに「マイKW設定」ボタンおよび専用モーダルUIを新設。
  - 登録されたマイKWは、SQLのLIKE事前抽出（省メモリ・0MB）により記事タイトル・本文・ユーザー名から瞬時に検知。
  - 検知時は専用の紫ピルバッジ（`🎯 マイKW検知: "xxx"`）で視認性高く表示され、CSV出力にも反映。
  - 総合テストスイートに `test_my_keywords_feature` を追加。

## [2.20261015.6] - 2026-10-15

### Added & Improved
- **検知キーワード（シグネチャ）のGitHub自動同期機能:**
  - `signatures.json` によるキーワード・不審ドメインの外部定義化。
  - ヘッダーに「最新KW更新 (GitHub)」ボタンを新設。ワンクリックで GitHub (Raw) から最新シグネチャを同期・即時再スキャン。
  - GitHub 障害時・オフライン時も組み込み定義へ自動フォールバック。
- **一覧画面における検知理由の即時可視化（タイトル直下ピルバッジ）:**
  - タイトルおよびユーザー名の直下に色分けされた視認性の高いピルバッジ（`🚨 本文改ざん痕跡: "hacked by"`、`🚨 タイトル改ざん: "trenggalek"` 等）を配置。横スクロール不要で検知理由を一目で把握可能に。
  - 該当記事のみピンポイントでマッチ単語を特定表示し、メモリ消費ゼロ（0MB）を完全維持。
- **総合テストスイート拡張:**
  - `test_signature_engine` を追加し、シグネチャ同期・UI表示の自動検証をパス。

## [2.20261015.4] - 2026-10-15

### Fixed & Optimized
- **大規模サイトでの通信エラー（HTTP 500 / 504）の根本解決:**
  - 投稿本文（`post_content`）を PHP メモリに全件ロードする方式を完全廃止。
  - 本文内の脅威シグネチャ（`Hacked by...` 等）およびスパムコードを SQL の WHERE 句で超高速事前抽出する方式へ最適化（メモリ消費量 99% 削減・0MB 化）。
  - クライアント通信エラーハンドリングの強化: サーバー側の HTTP ステータスやエラー応答をダイアログに詳細表示する `safeFetchJson` を導入。
  - `check_ajax_referer` の非致命的（non-fatal）処理化: トークン失効時に `-1` 終了ではなく適切な JSON 403 エラーを返すように統一。

## [2.20261015.3] - 2026-10-15

### Security & Hardening
- **単一サイト／マルチサイト（ネットワーク vs サブサイト個別）UI・権限の完全分離と厳格化:**
  - 単一サイト画面でマルチサイト関連UI（全傘下サイト、サイト選択等）が一切表示されないよう厳密ガード。

  - ネットワーク横断操作の特権昇格防止（`manage_network` 必須化、他サイト投稿削除の特権チェック）。
  - 不審ユーザー一括削除時の特権管理者（Super Admin）保護ガード（攻撃シグネチャに明示一致しない限り削除スキップ）。

  - 総合テストスイート `scripts/test_sweeper.py` を追加。
