# CHANGELOG

## [2.20261015.1] - 2026-10-15

### Added
- **マルチサイト（サイトネットワーク管理）完全対応:**
  - サイトネットワーク管理画面（`/wp-admin/network/`）での全子サイト横断スキャン・一括駆除機能。
  - 子サイト別絞り込みドロップダウンフィルターおよび対象サイト列の追加。
- **事故防止の多重安全ガード機構:**
  - トップページ等のシステム重要ページの削除完全除外・保護。
  - 公開中（publish）記事の誤完全削除ブロック（ゴミ箱へ安全フォールバック）。
  - 不審ユーザー削除時の公開記事所有権安全移譲（`wp_delete_user($uid, $reassign)`）。
- **網羅的検知シグネチャの強化:**
  - 改ざん・ハッカー署名（`Hacked by...`, `trenggalek`, `wp2shell` 等）。
  - SEOスパム、オンラインカジノ、医薬品、隠しスクリプト、使い捨てメアドドメイン。
- **Qlypx方式のバージョン管理導入:**
  - `MAJOR.YYYYMMDD.BUILD` 形式および `check_version_sync.py` による自動同期検証。
