# WP Incident Sweeper — 仕様書

**バージョン**: `2.20261015.2`

## 1. 動作要件
- WordPress: 5.8 以上
- PHP: 7.4 以上（PHP 8.0, 8.1, 8.2, 8.3 対応）
- 構成: 単体WordPress、およびマルチサイト（サブディレクトリ/サブドメイン型）

## 2. 機能仕様
1. **全コンテンツ高速クロール:**
   - 投稿（post）、固定ページ（page）、公開カスタム投稿タイプを網羅。
   - `publish`, `draft`, `pending`, `future`, `private`, `trash` の全ステータスを取得。
   - `$wpdb` 直接クエリによる省メモリ・ストリーム抽出（数万件規模でも安定動作）。
2. **マルチサイト横断スキャン:**
   - サイトネットワーク管理画面（`/wp-admin/network/`）において `switch_to_blog` で全傘下子サイトをループ。
3. **インシデント・スパム自動検知:**
   - 🚨 危険（高）: 改ざんシグネチャ、不審ユーザー作成記事。
   - ⚠️ 警告（中）: スパム・カジノ・不正コード・隠しテキスト。
   - ℹ️ 要確認（低）: 下書き・ゴミ箱。
4. **安全ガード機構:**
   - システム重要ページの保護（`page_on_front`, `page_for_posts`, `wp_page_for_privacy_policy`）。
   - 公開中正常記事の完全削除拒否・ゴミ箱フォールバック。
   - 不審ユーザー削除時の公開記事所有権安全移譲。
   - 自身アカウントおよび初期マスター管理者（ID: 1）の削除絶対禁止。
5. **エビデンスCSVエクスポート:**
   - UTF-8 BOM付きCSV形式での監査結果ダウンロード。
