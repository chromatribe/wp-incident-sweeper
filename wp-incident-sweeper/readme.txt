Emergency incident sweeper and security auditing plugin for single and multisite WordPress installations.

== Description ==

Scans all posts, pages, custom post types (including drafts, pending, private, and trash) and users across single and multisite network setups. Detects defacements (e.g. "Hacked by..."), suspicious dormant users, and SEO spam, allowing one-click bulk remediation with multi-layered safety guards.
