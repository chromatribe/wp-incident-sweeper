# WP Incident Sweeper (インシデント一括巡回・駆除スイーパー)

WordPressサイト内の**全投稿・固定ページ・全カスタム投稿タイプ（公開・下書き・保留・ゴミ箱含む）**および**全登録ユーザー**を瞬時に一括スキャンし、不正侵入の痕跡（`Hacked by...`、`wp2_*` アカウント等）を自動判定・ワンクリックで完全駆除できる緊急監査プラグインです。

---

## 🌟 主な機能

1. **全コンテンツ高速クロール:**
   - 投稿（post）、固定ページ（page）、すべてのカスタム投稿タイプを網羅。
   - ステータス（公開中、下書き、レビュー待ち、予約投稿、非公開、ゴミ箱）を完全チェック。
2. **インシデント・スパム自動検知:**
   - 🚨 **危険（高）:** `Hacked by...`、`trenggalek`、`wp2shell` 等の改ざんシグネチャ、および不審ユーザーが作成した記事。
   - ⚠️ **警告（中）:** カジノ・スパムワード、`<script>`、`eval()` 等の不審なコード片。
   - ℹ️ **要確認（低）:** 下書き、非公開、ゴミ箱に入っているコンテンツ。
3. **ユーザー監査（wp2_* / 7月登録ユーザー検知）:**
   - `wp2_` から始まるアカウントや `@wp2shell.invalid` アドレスを自動ハイライト。
   - 2026年7月の脆弱性インシデント期間（7/17〜7/25）に登録されたアカウントを検知。
4. **一括アクション（完全削除 / ゴミ箱移動）:**
   - 「🚨 危険項目を一括選択」ボタンで瞬時にチェック。
   - 「選択した項目を完全削除（ゴミ箱を経由せず即時消去）」または「ゴミ箱へ移動」。
   - 不審ユーザー削除時は、**そのユーザーが作成した全コンテンツ（下書き等）も同時消去**。
5. **CSVレポート出力（エビデンス保全）:**
   - スキャン結果（全記事・ユーザーの判定結果）をUTF-8 BOM付きCSVでダウンロード。
   - インフラチームや上長への巡回完了報告・証拠資料として即活用可能。
6. **ゼロ・フットプリント（安全設計）:**
   - 外部通信なし、外部CDN非依存、データベースに独自テーブルやゴミ設定を一切残しません。
   - 巡回完了後はプラグインを停止・削除するだけで綺麗に撤去できます。

---

## 🚀 使い方

1. **プラグインのインストール:**
   - 本リポジトリ内の `wp-incident-sweeper.zip` をダウンロード。
   - WordPress管理画面の `プラグイン > 新規追加 > プラグインのアップロード` からZIPを選択して有効化。
2. **スキャン画面を開く:**
   - 管理画面の左メニューに追加された **「巡回スイーパー」**（盾のアイコン）をクリック。
   - 自動的にサイト内の全コンテンツとユーザーがクロールされます。
3. **確認と駆除:**
   - 危険なアイテムがあれば赤色でハイライトされます。
   - 「🚨 危険項目を一括選択」をクリックし、「選択した項目を完全削除」を実行。
   - 「ユーザー監査」タブに切り替え、不審ユーザーがいれば同様に削除。
4. **CSV出力:**
   - 右上の「結果をCSV出力」からレポートをダウンロード。
5. **完了後の削除:**
   - 巡回が終わったら、プラグイン一覧から停止・削除してください。
