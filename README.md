# WP Incident Sweeper (インシデント一括巡回・駆除スイーパー)

**Version:** `2.20261015.5`

WordPressサイト内の**全投稿・固定ページ・全カスタム投稿タイプ（公開・下書き・保留・ゴミ箱含む）**および**全登録ユーザー**を瞬時に一括スキャンし、不正侵入の痕跡（`Hacked by...`、`wp2_*` アカウント等）を自動判定・安全にワンクリックで完全駆除できる緊急監査プラグインです。

マルチサイト（サイトネットワーク管理画面 `/wp-admin/network/`）にも完全対応しており、傘下の全子サイトを一括横断スキャン可能です。

---

## 🌟 主な機能

1. **マルチサイト（サイトネットワーク管理）完全対応:**
   - サイトネットワーク管理画面（`/wp-admin/network/`）にて「ネットワークで有効化」。
   - 傘下の全子サイト（サブサイト）のコンテンツ・ユーザーを一括横断クロール。
   - サイト別絞り込みフィルター＆対象サイトごとの個別編集リンクを完備。
2. **全コンテンツ高速クロール:**
   - 投稿（post）、固定ページ（page）、すべてのカスタム投稿タイプを網羅。
   - ステータス（公開中、下書き、レビュー待ち、予約投稿、非公開、ゴミ箱）を完全チェック。
3. **インシデント・スパム自動検知:**
   - 🚨 **危険（高）:** `Hacked by...`、`trenggalek`、`wp2shell` 等の改ざんシグネチャ、および不審ユーザーが作成した記事。
   - ⚠️ **警告（中）:** カジノ・スパムワード、`<script>`、`eval()` 等の不審なコード片。
   - ℹ️ **要確認（低）:** 下書き、非公開、ゴミ箱に入っているコンテンツ。
4. **多重安全ガード（巻き込み事故ゼロ設計）:**
   - システム重要ページ（トップページ、ブログ一覧、プライバシーポリシー）の絶対保護。
   - 公開中（publish）記事の誤完全削除ブロック（ゴミ箱へ安全フォールバック）。
   - 不審ユーザー削除時の公開記事所有権安全移譲（`wp_delete_user($uid, $reassign)`）。
   - 自身アカウントおよび初期マスター管理者（ID: 1）の削除絶対禁止。
5. **CSVレポート出力（エビデンス保全）:**
   - スキャン結果（全記事・ユーザーの判定結果）をUTF-8 BOM付きCSVでダウンロード。
   - インフラチームや上長への巡回完了報告・証拠資料として即活用可能。
6. **ゼロ・フットプリント（安全設計）:**
   - 外部通信なし、外部CDN非依存、データベースに独自テーブルやゴミ設定を一切残しません。
   - 巡回完了後はプラグインを停止・削除するだけで綺麗に撤去できます。

---

## 🚀 使い方

1. **プラグインのインストール:**
   - 本リポジトリ内の `wp-incident-sweeper.zip` をダウンロード。
   - 単体サイト: `プラグイン > 新規追加 > プラグインのアップロード` から有効化。
   - マルチサイト: `サイトネットワーク管理 > プラグイン > 新規追加` からネットワーク有効化。
2. **スキャン画面を開く:**
   - 管理画面の左メニューに追加された **「巡回スイーパー」**（盾のアイコン）をクリック。
   - 自動的にサイト内の全コンテンツとユーザーがクロールされます。
3. **確認と駆除:**
   - 危険なアイテムがあれば赤色でハイライトされます。
   - 「🚨 危険項目を一括選択」をクリックし、「選択した項目を完全削除」または「ゴミ箱へ」を実行。
   - 「ユーザー監査」タブに切り替え、不審ユーザーがいれば同様に削除。
4. **CSV出力:**
   - 右上の「結果をCSV出力」からレポートをダウンロード。
5. **完了後の削除:**
   - 巡回が終わったら、プラグイン一覧から停止・削除してください。
